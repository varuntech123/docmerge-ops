# DocMerge Ops — Intranet Dashboard

Modern intranet dashboard for document merge operations, signed PDF tracking, and secure workflow management.

---

# Overview

DocMerge Ops is a browser-based internal operations dashboard designed to simulate enterprise-level document processing workflows.

The application provides:
- Upload management
- Merge tracking
- Signed PDF handling
- Email dispatch workflows
- Secure dashboard interface
- Responsive dark-mode UI

Built entirely using:
- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Font Awesome

---

# Features

## Authentication System
- Administrator Login
- Operator Login
- Role-based workflow simulation

## Upload Management
- Drag & Drop file upload
- Excel validation workflow
- Upload status tracking

## Merge Operations
- Merge queue simulation
- Processing status updates
- Merge completion tracking

## Signed PDF Workflow
- Signed document tracking
- Email confirmation workflow

## Dispatch System
- Secure dispatch interface
- Mock SMTP workflow
- Dispatch confirmation handling

## UI & Experience
- Dark modern dashboard
- Fully responsive layout
- Sidebar navigation
- Animated interface
- Mobile-friendly design
