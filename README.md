# DocMerge Ops — Intranet

A lightweight browser-based intranet tool for managing client document merges, signed PDFs, and secure dispatch workflows.

---

## Features

- Secure Login Simulation
- Upload Dashboard
- Excel Validation Workflow
- Merge Tracking
- PDF Signature Management
- Secure Dispatch System
- LocalStorage Persistence
- Responsive Dark UI

---

## Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Font Awesome
